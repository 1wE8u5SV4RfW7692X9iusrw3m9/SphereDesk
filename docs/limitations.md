# 已知限制

- 真实模式在主显示器上铺一层透明球面，并在启动时关闭“显示桌面图标”。托盘“退出”时恢复。若这层窗口创建失败，则退回普通窗口，并且不改图标开关。
- 球面盖住主显示器的桌面区域。其他普通窗口在前面时会盖住它。空白处的系统桌面右键菜单在程序运行期间不可用。
- 球面以外的像素是透明的，壁纸会透出来。操作面板仍是普通窗口。
- 不移动、不重命名、不删除真实文件，也没有回收站或撤销。
- 不显示回收站、此电脑、网络等 Shell 虚拟图标。
- 只扫描桌面顶层。子文件夹里的内容不会出现在球面上。
- 同时带隐藏和系统属性的项目，以及名为 `desktop.ini` 的文件，会跳过，以接近资源管理器的默认桌面。
- 图片缩略图未做，球面使用系统图标。图标暂时取不到时显示占位图形。
- 公共桌面如果没有权限，只标记该来源不可用，不会提升整个进程。
- 快捷方式的解析不替代项目身份。打开时交给系统，保留快捷方式自己的目标、参数和工作目录。
- 监听可能丢事件。溢出、唤醒、手动刷新和定时补扫会重新核对。失败的来源会退避，避免持续访问。
- 高密度时不会保证每个文件名同时可读。悬停、选中和前景标签优先。
- 没有自动更新、MSIX、单文件压缩或 ARM64 包。
- 可以另外生成未签名的 Inno Setup 安装包。本机语言目录没有简体中文脚本，安装向导使用默认语言。安装不请求管理员权限。
- 没有诊断导出。日志默认不写完整用户路径。
- 未签名。不要关闭 SmartScreen 或其他系统防护来运行它。
