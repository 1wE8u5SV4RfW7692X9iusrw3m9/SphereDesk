# 操作说明

SphereDesk 把真实桌面的文件排到壁纸上的球面里。其他窗口照常盖住它。它不移动、不删除文件。

## 桌面图标

启动时会关闭系统的“显示桌面图标”。托盘菜单里的“退出”会把它恢复。

如果程序没有正常退出，图标仍然不在：

1. 在桌面空白处单击右键。
2. 选择“查看”。
3. 重新勾选“显示桌面图标”。

下次启动 SphereDesk 时，如果发现上次没有恢复，也会先把这个开关设回去。

## 球面

- 空闲时球面缓慢旋转。鼠标进入球面区域后暂停。
- 按住左键并拖动可以旋转。拖动超过系统判定的距离后，松手不会打开文件。
- 单击选中，双击使用系统默认方式打开原始文件、`.lnk` 或 `.url`。
- 背面图标颜色更淡，不能直接打开。搜索或“定位到正面”可以把它转到前面。
- 设置里可以关闭自转、调节速度，或打开“减少动画”。减少动画会关闭自转、惯性和转场。

## 搜索和列表

搜索框按名称过滤，旁边的下拉框按类型过滤。Enter 打开当前项，Esc 清空搜索。下方列表是键盘和屏幕阅读器使用的真实控件，双击或 Enter 同样会打开。

## 虚拟分组

左侧可以新建、重命名、删除分组。选择一个分组后，用“加入分组”或“移出当前分组”改变分类。

这些操作只改 SphereDesk 的配置，不移动、不删除文件。删除分组也不会删除文件。选择“全部”可以重新看到所有项目。“重新均匀排列”只重排球面上的位置。

## 操作面板、托盘和热键

平时只看球面。默认热键 Ctrl+Alt+D 打开搜索、分组和设置；再按一次收起面板。托盘图标单击也会打开面板。如果热键被占用，程序会提示，并可以在设置里更换。

面板上的关闭只收起面板。退出程序要用托盘菜单里的“退出”，这时才会恢复原来的桌面图标，并释放监听、热键和托盘图标。

`SphereDesk.exe --synthetic` 打开普通窗口和样例数据，不挂到桌面，也不改桌面图标。

配置损坏时，程序会把坏文件隔离，并尝试读取上一份备份。图标缓存可以整目录删除，分组配置不会因此丢失。
